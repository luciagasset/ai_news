Desde hace una semana, usuarios de Claude Code y Claude Opus 5.5 denuncian que el modelo se niega a trabajar con videojuegos y a hacer ingeniería inversa, es decir, a analizar un programa para ver cómo funciona. En GitHub hay quejas por bloqueos a mitad de desarrollo o al replicar una mecánica. El usuario de Twitter Chasm atribuye los de juegos a una regla que veta recrear un juego existente, «aunque se renombre». Ese texto no está confirmado.

Anthropic no se ha pronunciado. Tom's Hardware cree que busca evitar demandas de empresas de software, tras la ola de clones hechos con IA, y no descarta un vínculo con sus restricciones de ciberseguridad del 6 de octubre. Los críticos ven una ironía: estas empresas copiaron información ajena para entrenar sus modelos y ahora temen por los derechos de autor. For the past week, users of Claude Code and Claude Opus 5.5 have reported that the model refuses to work on video games and to do reverse engineering, that is, analyzing a program to see how it works. On GitHub there are complaints about blocks halfway through development or when replicating a game mechanic. Twitter user Chasm attributes the game-related blocks to a rule against recreating an existing game, "even if it is renamed". That text is unconfirmed.

Anthropic has not commented. Tom's Hardware believes the company wants to avoid lawsuits from software firms, after the wave of AI-made clones, and does not rule out a link to its cybersecurity restrictions of October 6. Critics see an irony: these companies copied other people's information to train their models and now worry about copyright. Some users suggest switching to open or local models.
