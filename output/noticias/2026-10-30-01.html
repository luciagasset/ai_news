Phorion ha detectado una puerta trasera en la extensión oficial Claude Code for VS Code del Cursor Marketplace, la tienda de extensiones del editor Cursor. Cursor ha retirado las versiones 2.1.312 y 2.1.313, y su aviso de seguridad las señala como afectadas en macOS y Windows. El código malicioso se ejecuta al cargar la extensión, sin que el usuario haga nada. Añade una clave SSH del atacante, abre un túnel hacia su servidor y sigue activo tras reiniciar.

También envía datos del equipo y los nombres de hasta 40 variables de entorno con claves o tokens, no sus valores. Un fallo del malware hace que, con una cuenta normal, no active SSH en los Mac que lo tienen apagado. El acceso queda preparado si se enciende después. Desinstalar no basta: Phorion recomienda cerrar los túneles, borrar la persistencia y la clave, y cambiar las credenciales si SSH estaba activo o hubo un acceso.

Phorion has detected a backdoor in the official Claude Code for VS Code extension on the Cursor Marketplace, the extension store for the Cursor editor. Cursor has removed versions 2.1.312 and 2.1.313, and its security notice identifies them as affected on macOS and Windows. The malicious code runs when the extension loads, with no action from the user. It adds an attacker's SSH key, opens a tunnel to the attacker's server and stays active after a reboot.

It also sends host data and the names of up to 40 environment variables holding keys or tokens, not their values. A bug in the malware means that, on a standard account, it does not turn on SSH on Macs where it is off. The access remains ready if SSH is turned on later. Uninstalling is not enough: Phorion recommends closing the tunnels, deleting the persistence and the key, and rotating credentials if SSH was on or there was a login.
