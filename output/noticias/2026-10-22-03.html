Los agentes son más útiles cuando pueden leer ficheros, instalar paquetes, llamar a APIs y usar credenciales. OpenShell busca darles esa capacidad sin acceso libre a los datos, secretos o red del usuario. Cada agente corre en un entorno aislado, y el núcleo del sistema controla cada acceso a ficheros, llamada al sistema y conexión de red. Los agentes nunca ven las credenciales reales: OpenShell las añade solo a las peticiones dirigidas a destinos aprobados.

Antes de aplicar un cambio de política, OpenShell usa verificación formal para detectar accesos nuevos de riesgo, como llegar a otro servidor con credenciales. Esos cambios esperan revisión humana. La versión 0.1 trae un calendario de versiones estable, nuevas APIs y más opciones de extensión. Funciona en Linux, macOS con Apple Silicon y, de forma experimental, Windows con WSL 2. Tiene SDK para Python, TypeScript, Go y Rust, y licencia Apache 2.0. Recoge telemetría anónima, que se puede desactivar.

Agents are most useful when they can read files, install packages, call APIs and use credentials. OpenShell aims to give them that capability without free access to the user's data, secrets or network. Each agent runs in an isolated sandbox, and the system kernel controls every file access, system call and network connection. Agents never see the real credentials: OpenShell adds them only to requests bound for approved endpoints.

Before applying a policy change, OpenShell uses formal verification to flag risky new access, such as reaching another host with credentials. Those changes wait for human review. Version 0.1 brings a stable release cadence, new APIs and more extension options. It runs on Linux, macOS on Apple Silicon and, experimentally, Windows with WSL 2. It has SDKs for Python, TypeScript, Go and Rust, and an Apache 2.0 license. It collects anonymous telemetry, which can be disabled.
